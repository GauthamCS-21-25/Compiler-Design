1 - Start  
2 - Declare constants and variables  
   2.1 - Define MAX_STATES = 100 (maximum number of states)  
   2.2 - Define MAX_SYMBOLS = 10 (maximum number of input symbols excluding epsilon)  
   2.3 - Define Node structure with `state` (destination state) and `next` (pointer to next node)  
   2.4 - Declare global arrays for epsilon and non-epsilon transitions  
      2.4.1 - epsilonAdj[MAX_STATES] for epsilon transitions  
      2.4.2 - nonEpsilonAdj[MAX_STATES][MAX_SYMBOLS] for non-epsilon transitions  
   2.5 - Declare alphabet[MAX_SYMBOLS] to store input symbols excluding epsilon  
   2.6 - Declare isFinalOriginal[MAX_STATES] to mark final states in the original NFA  
   2.7 - Declare closure[MAX_STATES][MAX_STATES] to store ε–closure for each state  
   2.8 - Declare n (number of states) and m (number of transitions)  

3 - Define functions  
   3.1 - addEdge(Node **head, int to)  
      3.1.1 - Allocate memory for a new Node  
      3.1.2 - Set state of the new Node to `to`  
      3.1.3 - Set next of the new Node to the current head  
      3.1.4 - Set head to the new Node (prepend the new node)  
      3.1.5 - Handle memory allocation failure using `perror`  

   3.2 - computeEpsilonClosure(int state, int visited[])  
      3.2.1 - Mark visited[state] as 1 (state is visited)  
      3.2.2 - Traverse epsilon transitions of the state  
         3.2.2.1 - For each transition, if the destination state is not visited, call computeEpsilonClosure for that state  

   3.3 - computeAllEpsilonClosures()  
      3.3.1 - For each state, compute its ε–closure using computeEpsilonClosure  
      3.3.2 - Store the ε–closure in the closure array  

   3.4 - isInSet(int set[], int size, int element)  
      3.4.1 - Check if `element` is in `set`  

4 - Main function  
5 - Input number of states (n)  
   5.1 - If input is invalid, print an error message and exit  
   5.2 - If n exceeds MAX_STATES, print an error message and exit  

6 - Input number of transitions (m)  
   6.1 - If input is invalid, print an error message and exit  

7 - Input number of input symbols (excluding epsilon) and the symbols  
   7.1 - If input is invalid, print an error message and exit  
   7.2 - Read the symbols and store them in `alphabet`  

8 - Input transitions (from_state input_symbol to_state)  
   8.1 - For each transition, if the symbol is 'e' (epsilon), add it to the epsilonAdj list  
   8.2 - If the symbol is not epsilon, find its index in the alphabet and add it to the corresponding non-epsilon transition list  

9 - Input the final states of the original NFA  
   9.1 - For each final state, mark it in `isFinalOriginal`  

10 - Compute the ε–closure for each state  
   10.1 - Call computeAllEpsilonClosures() to compute and store the ε–closure for every state in `closure`  

11 - Convert the NFA with ε–transitions to one without ε–transitions  
   11.1 - For each state and each input symbol, compute the new transitions based on the ε–closure of the destination states  
   11.2 - For each transition, print the resulting destinations in the new NFA  

12 - Determine the new set of final states  
   12.1 - A state is final if any state in its ε–closure was final in the original NFA  
   12.2 - Print the new final states  

13 - Free all allocated memory for epsilon and non-epsilon transition lists  
   13.1 - For each state, free the epsilon transition list  
   13.2 - For each state and each symbol, free the non-epsilon transition lists  

14 - End
